## 一、Feature 概述

实现 cross_cutting 层的安全相关 2 个模块：
- **`cross_cutting_audit_recorder`**：当 guardrail 拦截 / PII 泄露 / 越权 tool 调用 / prompt injection 时，append-only 写入 `AuditEntry`。
- **`cross_cutting_guardrail_middleware`**：根据 `ToolSideEffect` 标注决定是否触发 LangGraph `interrupt()`；实现 LangChain `AgentMiddleware` 协议，注入到 LangGraph 图。

这是 LangAgent 安全护栏（Guardrails）的唯一实现入口。

### 3.3 审计写入策略

- **append-only**：`write()` 永不修改历史条目；写失败抛 `AuditFlushError`，退出码 4（I/O 错误）。
- **写入路径**：`~/.local/share/langagent/audit.jsonl`（一行一条 JSON）。
- **脱敏**：`evidence` 字段中的 `api_key` / `password` / `token` / 邮件地址 / 手机号在写盘前替换为 `***`。
- **查询接口**：`query(category, since)` 返回 list[AuditEntry]，仅按 `category` 精确匹配 + `audited_at >= since` 过滤。

#### 3.4b ToolSpec.requires_approval × side_effects 真值表（**review.md v2.2.0 修复 P2-6 新增**）

> 本节是 F09 `evaluate()` 决策逻辑的"穷举真值表"，覆盖 `ToolSpec.requires_approval`（True / False）+ `side_effects`（声明 NONE / 声明敏感 / 未声明）3 维 6 组合的真值。开发者可据此决定 tool 该如何标注。

| `ToolSpec.requires_approval` | `ToolSpec.side_effects` | 触发 audit log | `GuardrailDecision.allow` | `GuardrailDecision.interrupt` | 来源（主链 / 次要） |
|---|---|---|---|---|---|
| `True` | 任意（含 `none`） | AuditEntry(category=unauthorized_tool) | **False** | **True** | **主链**（review.md v2.2.0 P2-7） |
| `False` | `[ToolSideEffect.NONE]`（开发者显式声明无副作用） | — | True | False | 默认（allow） |
| `False` | `[ToolSideEffect.READ_FILE]` | — | True | False | 默认（allow；读文件可观察） |
| `False` | `[ToolSideEffect.WRITE_FILE]` / `EXEC_SHELL` / `NETWORK_CALL` / `SEND_MESSAGE` / `EXTERNAL_STATE` | AuditEntry（仅非 NONE 敏感操作） | False | True | 默认（interrupt + audit） |
| `False` | **`未声明 SIDE_EFFECTS`**（F04 loader 填默认 `[ToolSideEffect.NONE]`） | AuditEntry(category=unauthorized_tool) + F04 `la.tool.suspicious_missing_side_effects` 警告 | False | True | **次要防御**（review.md v2.2.0 P1-5） |

> **关键不变量**：
> 1. **`requires_approval == True` 永远 interrupt**（即便 `side_effects=[NONE]`），不依赖 side_effects 列表；
> 2. **`side_effects=[NONE]` 不等于"安全"**——必须配合 `requires_approval=False` 才真正放行；
> 3. **`未声明 SIDE_EFFECTS`** 视为最不利情况，强制 deny-CLOSED + audit；
> 4. **`network_call` 决策细则见 §3.4a**（内网 endpoint 默认 allow，公网 endpoint 默认 interrupt）。

### 3.4a 内网 endpoint 决策细则（**review.md v1.0.0 P2-8 修复新增**）

`network_call` 是宪法第 X 条 1 款"不外发数据"的兜底机制，但本地 OpenAI Compatible（vLLM Qwen3.8-27B）也走 `ChatOpenAI` 协议 + `base_url` 实际是网络调用（即便内网）。如果一律 interrupt，会误伤宪法第 IV 条 4 款要求的默认模型。

**决策算法**（`evaluate()` 内部）：

```python
def evaluate(side_effects, config, policy):
    if "network_call" not in side_effects:
        return GuardrailDecision(allow=True, reason="no network_call")

    endpoint = config.model_base_url  # 当前模型 endpoint
    if policy.allow_internal_endpoints and is_internal(endpoint, policy.internal_endpoint_patterns):
        # 内网 endpoint（vLLM 等）→ 默认 allow
        return GuardrailDecision(
            allow=True, interrupt=False,
            is_internal_endpoint=True,
            reason=f"internal endpoint {endpoint} matched internal_endpoint_patterns",
        )

    # 公网 / 外部 endpoint → interrupt + audit
    return GuardrailDecision(
        allow=False, interrupt=True, redact=False,
        is_internal_endpoint=False,
        reason=f"public endpoint {endpoint} blocked by default",
    )

def is_internal(endpoint: str, patterns: list[str]) -> bool:
    """检查 endpoint 是否命中内网 pattern。endpoint 形如 'http://10.0.0.5:8000/v1'。"""
    from urllib.parse import urlparse
    import ipaddress
    parsed = urlparse(endpoint)
    host = parsed.hostname or ""
    for pat in patterns:
        # 支持 IP CIDR / IP 通配符 / hostname glob
        try:
            ip = ipaddress.ip_address(host)
            if ip in ipaddress.ip_network(pat, strict=False):
                return True
        except ValueError:
            # hostname glob match:fn
            if fnmatch.fnmatch(host, pat):
                return True
    return False
```

**用户配置**（`.env`）：

```bash
LANGAGENT_GUARDRAIL_ALLOW_INTERNAL_ENDPOINTS=true
LANGAGENT_INTERNAL_ENDPOINTS=10.0.0.0/8,192.168.0.0/16,*.internal.example.com
```

## 五、关键约束

1. **append-only 刚性**：审计文件不得 truncate / overwrite；写入失败必须抛错而非静默丢。
2. **默认 deny-all 敏感操作**：网络调用 / shell 执行 / 文件写入默认 interrupt；用户不得"一键放行"所有（宪法第 X 条 2 款）。
3. **PII / 密钥脱敏**：api_key / password / token / email / phone 在写盘前替换；测试必须验证。
4. **prompt injection 防御**：来自 tool 返回值 / 检索片段的文本不直接拼进 system prompt；middleware 标记 untrusted content（宪法第 X 条 3 款）。
5. **不外发数据**：guardrail 不调用任何外部服务（如云端 PII 检测）；检测必须本地启发式（宪法第 X 条 1 款）。
6. **依赖 LangChain `AgentMiddleware` 协议**：F09 是 LangAgent 与 LangChain middleware 的接触面；类型注解必须严格匹配。
7. **依赖方向**：cross_cutting 不依赖 runtime / cli / protocol_skill_loader / protocol_tool_registry；仅 primitives（类型注解）+ cross_cutting_logger + protocol_event_bus + cross_cutting_audit_recorder。
8. **TDD 刚性**：先 Red 后 Green 再 Refactor；mock 真实 LangGraph 中间件链（让协议跑通而非跳到图）。
9. **第 XV 条对齐清单**：与宪法第 VII 条（middleware 接入方式）/ 第 IX 条（Guardrails 子能力）/ 第 X 条（安全与隐私）/ 第 XIII 条逐项对齐。
