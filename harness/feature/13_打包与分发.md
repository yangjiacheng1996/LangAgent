## 一、Feature 概述

把 LangAgent 整套代码打包成：
1. **单文件可执行二进制**（PyInstaller）：用户在无 Python 环境的机器上直接 `./langagent run <agent-dir>` 运行。
2. **离线 wheels 包**：内网 PyPI 镜像预装依赖；首次运行不触网（宪法第 XI 条 4 款）。

本 feature 是宪法第 XI 条"打包与分发"的实现；不引入新模块，仅构建脚本 + 验证流程。

## 二、必读顶层设计 artefact（宪法第 XV 条）

1. `harness/top_level_design/workflow.md` —— 4 个核心子命令的最终行为；打包后必须全部可执行。
2. `harness/top_level_design/architecture_modules.md#mod-cli-runner` —— CLI 入口 `langagent/__main__.py` 必须能被 PyInstaller 找到。
3. 宪法第 XI 条（打包与分发）—— 5 款硬约束。
4. 宪法第 X 条 5 款（密钥管理）—— `.env` 不入构建产物；CI 日志禁止打印密钥。

**本 feature 重点对齐的宪法条款**（**review.md v2.2.0 修复 P2-9**）：
- **第 I 条** 项目身份与边界：F13 把 LangAgent 打包成"二进制命令"入口（与宪法第 I 条 2 款对齐）；
- **第 II 条** 技术栈与依赖范围：wheels 包须可内网 PyPI 镜像拉取（不触公网）；
- **第 III 条** LangSmith 剥离：spec excludes 列表显式登记 5 项 LangSmith 集成路径；
- **第 XI 条** 打包与分发：F13 是该条款的核心实施方（PyInstaller 单文件 + wheels 离线包 + 版本号 + commit hash + 不打包用户 .env）；
- **第 X 条** 安全与隐私：不打包密钥 / CI 打印脱敏。

### 3.3 离线 wheels 包生成

```bash
# scripts/build_wheels.sh
pip download -r requirements.lock.txt -d ./wheels/ --no-deps
# 产出 ./wheels/*.whl 在内网 PyPI 镜像可达
```

要求：`requirements.lock.txt` 锁定全部依赖版本（含 langchain / langgraph / 各 provider / pyinstaller 等）；`pip install --no-index --find-links=./wheels/` 必须成功。

> **评审 s-5 修复**：PyInstaller 自身版本须与 LangChain / LangGraph 的兼容矩阵已知。`requirements.lock.txt` 须锁定 `pyinstaller==6.*`（PyInstaller 6.x 对 Python 3.11 / 3.12 兼容最佳；5.x 在某些 hook 场景下对 langchain_community 不友好）。CI 锁定测试：构建完成后必须跑 `tests/build/test_wheels_isolation.py` 验证在断网容器中 `pip install --no-index --find-links=./wheels/ langagent` 成功。

### 3.4 版本号与 commit hash 注入

- 二进制启动时打印：`LangAgent v1.2.3 (commit a1b2c4d)`。
- 通过 `pyproject.toml` 的 `__version__` + `git rev-parse HEAD` 注入；CI 自动注入（避免手动同步）。

### 3.5 升级策略（宪法第 XI 条 5 款）

- LangAgent 主程序升级：不覆盖用户智能体目录的 `instructions.md` / `skills/` / `tools/`。
- 升级方式：用户替换 `./langagent` 二进制 + `~/.local/share/langagent/` 配置保留。
- 智能体目录升级：用户自行决定；升级脚本（`langagent upgrade --agent-dir`）不在 v1 范围（宪法未要求 v1 实现）。

### 3.6 LangAgent 主程序构建产物的 include / exclude 清单（**review.md v1.1.0 P1-9 修复后标题明确**）

**两类 `pyproject.toml` 区分**（F13 §3.6 + §3.2 + §三 容易混淆，必须明确）：
1. **LangAgent 主程序自身的 `pyproject.toml`**（F13 §七 deliverable 增 `[project.scripts]` + `[build-system]` 段）：**入构建产物**（PyInstaller 默认行为；这是构建系统层 metadata）。
2. **用户智能体目录的 `pyproject.toml`**（宪法第 V 条 2 款非可选；用户自维护）：**不入构建产物**（PyInstaller 静态分析不扫描智能体目录；用户在 `langagent init` 时自行维护；升级二进制不影响智能体目录）。

**Include 清单**（PyInstaller 默认行为）：
- `langagent/` Python 包源码（含 `__main__.py` 入口 + cli/ + runtime/ + protocol/ + cross_cutting/ + primitives/ + eval/ 子包）。
- 主程序 `pyproject.toml`（构建 metadata）。
- `requirements.lock.txt`（构建时用，不打包进二进制）。

**Exclude 清单**（PyInstaller spec 显式 + `.gitignore` 双重控制）：

`.env` / `__pycache__/` / `.git/` / `*.pyc` / `tests/` / `harness/` / `docs/`（如存在） / **用户智能体目录 `<agent-dir>/`（PyInstaller 静态分析不扫描）** —— 由 PyInstaller spec 显式 excludes + `.gitignore` 双重控制。

## 五、关键约束

1. **单文件二进制**：用户双击即可运行；不需要 Python 环境。
2. **离线安装**：首次运行不触网；wheels 包在内网 PyPI 镜像可达。
3. **不打包 .env**：密钥文件绝对不入产物；CI 必须 grep 验证。
4. **排除 LangSmith**：spec excludes 显式列出；运行时 `import langsmith` 抛 ImportError（验证）。
5. **版本号 + commit hash 注入**：构建时自动注入，避免手动同步。
6. **依赖锁定**：`requirements.lock.txt` 全部 `==X.Y.Z`；可复现构建。
7. **依赖方向**：本 feature 不属于 5 层架构；属于构建系统层；与 F01 唯一交集是 `langagent/__main__.py` 入口。
8. **TDD 刚性**：先 Red 后 Green 再 Refactor；构建脚本本身有测试；smoke test 在 CI 必跑。
9. **第 XV 条对齐清单**：与宪法第 I 条（项目身份 — 二进制入口）/ 第 II 条（依赖范围 — wheels 包须可内网拉取）/ 第 X 条 5 款（密钥管理）/ 第 XI 条（打包与分发 — 5 款硬约束）/ 第 XIII 条逐项对齐。

## 六、本 feature 不包含

- 不实现 `langagent upgrade --agent-dir` 命令（v1 不要求；用户在 init 时已备份）。
- 不实现 Docker 镜像打包（PyInstaller 二进制已可独立运行；不重复造轮子）。
- 不实现 `langagent --version` 子命令（如需版本号嵌入 `--help` 输出即可；不增加额外子命令）。
- 不实现自动签名 / notarization（公司内网分发不需要；用户从受信任渠道下载）。

## 八、与其它 feature 的边界

- **F01**：`langagent/__main__.py` 是 PyInstaller 的入口；F01 必须保证该文件可作为包入口被调用（`python -m langagent` 等价于 `langagent run`）。
- **F11**：F11 的 `langagent eval` 子命令必须在打包后二进制中正常工作；smoke test 必须覆盖 eval。
- **F02**：F02 的 `langagent init` 子命令必须在打包后正常工作；smoke test 必须覆盖 init。
- **不依赖 F03-F10 的运行时**：F13 仅复用 F01 入口，不调用 F03-F10 的具体模块（它们已被 F01 间接调用）。

## 九、风险与回滚

- **风险 1**：PyInstaller 与 LangChain / LangGraph 的版本兼容；遇到 hiddenimports 缺失时需手动 spec 调整。
- **风险 2**：单文件二进制体积过大；可通过 excludes 减小（已在 spec 中列出 tkinter / matplotlib 等）。
- **风险 3**：跨平台（macOS / Linux / Windows）差异；v1 仅支持 Linux x86_64（公司内网部署统一）。
- **回滚**：保留 `langagent/` Python 包形式作为 fallback；用户可 `pip install` 后 `python -m langagent` 使用。
