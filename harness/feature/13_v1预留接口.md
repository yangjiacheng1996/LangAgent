## 一、Feature 概述

为 6 个 v1 预留接口创建 Python 类型 stub（仅 Pydantic 模型 / TypedDict 定义，**不实现**任何业务逻辑）：
- `ChannelSpec`（Pydantic BaseModel, frozen）—— IM 通道规范
- `ChannelContext`（TypedDict, total=False）—— IM 通道上下文（嵌入 AgentState.context）
- `SandboxSpec`（Pydantic BaseModel, frozen）—— 文件系统 / shell 沙箱规范
- `ScheduleSpec`（Pydantic BaseModel, frozen）—— 定时调度规范
- `MemorySpec`（Pydantic BaseModel, frozen）—— 长期记忆规范
- `IdentitySpec`（Pydantic BaseModel, frozen）—— 调用者身份验证规范

所有 v1 实现的 `enabled = False`，由后续 v2+ feature 启用。

## 二、必读顶层设计 artefact（宪法第 XV 条）

1. `harness/top_level_design/module_schemas.md#schema-channel-spec` + `#schema-channel-context` + `#schema-sandbox-spec` + `#schema-schedule-spec` + `#schema-memory-spec` + `#schema-identity-spec` —— 6 个 schema 完整字段约束。

### 3.2 Schema 字段（来自 module_schemas.md）

```python
# ChannelSpec
class ChannelSpec(BaseModel, frozen=True):
    channel_id:   str                  # * 通道标识（如 'slack' / 'feishu' / 'dingtalk'）
    channel_type: str                  # * 'slack' / 'feishu' / 'dingtalk' / ...
    enabled:      bool = False         # - v1 预留接口，默认禁用
    config:       dict[str, Any] = {}  # - 通道专属配置（webhook / token / ...）

# ChannelContext
class ChannelContext(TypedDict, total=False):
    channel_id:  str
    user_id:     str
    thread_id:   str
    raw_message: str
    sender_meta: dict[str, Any]

# SandboxSpec
class SandboxSpec(BaseModel, frozen=True):
    sandbox_type: str                  # * 'docker' / 'firecracker' / 'local-subprocess' / ...
    enabled:      bool = False
    config:       dict[str, Any] = {}

# ScheduleSpec
class ScheduleSpec(BaseModel, frozen=True):
    schedule_id: str
    cron:        str
    enabled:     bool = False
    config:      dict[str, Any] = {}

# MemorySpec
class MemorySpec(BaseModel, frozen=True):
    memory_type: str                   # * 'sqlite' / 'postgres' / 'redis' / ...
    enabled:     bool = False
    config:      dict[str, Any] = {}

# IdentitySpec
class IdentitySpec(BaseModel, frozen=True):
    identity_type: str                 # * 'none' / 'api-key' / 'oauth' / 'iam'
    enabled:       bool = False        # - 默认禁用（v1 可选）
    config:        dict[str, Any] = {}
```

## 五、关键约束

1. **仅定义类型，不实现业务**：F13 不写 loader / runtime / IO；纯 Pydantic / TypedDict 定义。
2. **`enabled = False` 默认值刚性**：所有 6 个类型的 enabled 字段默认值必须是 False；测试断言。
3. **frozen 约束刚性**：5 个 Pydantic BaseModel 必须 `model_config = {"frozen": True}`；ChannelContext 是 TypedDict 无冻结概念但 total=False。
4. **schema_version 字段**：每个类型 class 必须有 `schema_version: str = "v0.1.0"` 类属性；用于未来版本迁移。
5. **不依赖 LangSmith**：纯类型定义；无运行时依赖。
6. **不实例化**：仅类型；不得在 F13 写任何 `ChannelSpec(channel_id=...)` 实际构造的业务代码。
7. **依赖方向**：属于 protocol 层的 v1 预留子包；不依赖 runtime / cli / cross_cutting / primitives。
8. **TDD 刚性**：先 Red 后 Green 再 Refactor；类型 stub 也必须测。
9. **第 XV 条对齐清单**：与宪法第 V 条（智能体目录契约 — 可选子项）/ 第 XII 条（schema_version 字段）/ 第 XIII 条逐项对齐。

## 六、本 feature 不包含

- 不实现 ChannelSpec 加载器（v2+）。
- 不实现 SandboxSpec 沙箱执行（v2+；v1 不实现 sandbox 子目录）。
- 不实现 ScheduleSpec cron 调度（v2+）。
- 不实现 MemorySpec 长期记忆（v2+）。
- 不实现 IdentitySpec 身份验证（v2+；v1 用户无需鉴权）。
- 不实现 ChannelContext 在 AgentState 中的 reducer（F08 v1 仅用 context 字段，不特判 ChannelContext）。
- 不在 langagent init 模板中生成 v1 预留配置文件（F06 仅生成空目录，不生成 yaml）。
