## 一、Feature 概述

实现 runtime 层阶段 1 `dir_load`：扫描智能体目录，校验宪法第 V 条布局（4 子目录 + `instructions.md`），加载系统提示词，扫描 skill / tool / middleware 列表，产出 `LoadedAgent` 句柄。

这是 `langagent init`（创建模板）与 `langagent run`（加载已存在智能体）共用的阶段入口。

### 3.4 阶段能力边界（避免 stage_capability_violation，**review.md v0.3.0 S-6 修复后**）

### 3.5a `agent.py` 模板内容示例（**review.md m-3 修复 + v0.4.0 M-NEW-5 修复明确**）

```python
# agent.py — 智能体入口；宪法第 V 条 2 款约束：必须导出名为 `agent` 的 CompiledStateGraph
from typing import Annotated, Any, TypedDict

# v0.4.0 M-NEW-5 修复：从 primitives 层 import reducer 与 LangGraph 类型（避免分层违反 + 符合宪法第 VI 条 2 款 5 字段约束）
from langagent.primitives.langchain_types import BaseMessage, add_messages      # review.md v0.3.0 M-3: 不直接 import langchain
from langagent.primitives.state_reducers import (                                # review.md v0.4.0 M-4 方案 C: reducer 从 primitives 层 import
    replace_with_merge, merge_dict, overwrite_or_merge,
)

# AgentState 完整 5 字段（与宪法第 VI 条 2 款 + module_schemas.md#schema-agent-state 对齐）
class AgentState(TypedDict, total=False):
    """LangAgent 主图 State；与 LangGraph 编译态直接对接。"""
    messages:   Annotated[list[BaseMessage], add_messages]              # LangGraph 内置 reducer
    todos:      Annotated[list[dict[str, Any]], replace_with_merge]     # primitives.state_reducers
    files:      Annotated[dict[str, dict[str, Any]], merge_dict]        # primitives.state_reducers
    context:    Annotated[dict[str, Any], overwrite_or_merge]           # primitives.state_reducers
    scratchpad: Annotated[dict[str, Any], replace_with_merge]           # **review.md v1.1.0 P2-1 修复补 Annotated[]**


def build_graph():
    from langgraph.graph import StateGraph, START, END  # 仅在本函数内 import 保持模板顶层 import 干净
    g = StateGraph(AgentState)
    def echo_node(state: AgentState) -> dict[str, Any]:
        last = state.get("messages", [None])[-1] if state.get("messages") else None
        content = getattr(last, "content", "no input") if last else "no input"
        return {"messages": [("assistant", f"echo: {content}")]}
    g.add_node("echo", echo_node)
    g.add_edge(START, "echo")
    g.add_edge("echo", END)
    return g.compile()


agent = build_graph()  # 宪法第 V 条 2 款：必须导出名为 agent 的 CompiledStateGraph
```

> **v0.4.0 M-NEW-5 修复说明**：模板使用完整 5 字段 AgentState（宪法第 VI 条 2 款硬约束）；reducer 函数全部从 primitives 层 import（避免分层冲突，符合 M-4 方案 C）；`langgraph.graph.StateGraph / START / END` 在函数内 import（保持模板顶层 import 最小化）。F06 §四.4a 增加测试 `test_write_template_default_agent_state_full_5_fields` 验证模板含完整 5 字段。
> 实际生产场景下，用户的 `agent.py` 可改为调用 F01 提供的 `primitives_state_graph_builder.build(loaded_agent, config, checkpoint)` 装配更复杂的图（含 middleware / tools / checkpointer）。模板作为最小可运行示例。

## 五、关键约束

1. **目录可移植性**：模板生成的 `instructions.md` / `tools/*.py` / `skills/<name>/SKILL.md` 中**不得**含绝对路径、内网 IP、用户名等机器相关字面量（宪法第 XIII 条 6 款）。
2. **不读 .env**：dir_load 阶段严格不读 `.env`，违反抛 `StageCapabilityViolationError`。
3. **不实例化模型**：同上。
4. **不编译图**：同上。
5. **fail-fast on non-optional missing**：仅当 `instructions.md` / `agent.py` / `pyproject.toml` 三个非可选文件缺失时立即抛错退出码 65；`skills/` / `tools/` / `middleware/` 缺失合法（**评审 m-3 修复后**）。
6. **v1 预留目录**：模板包含空的 `channels/` / `sandbox/` 目录但不加 `.gitkeep`（避免污染用户）。
8. **依赖方向**：runtime 不得反向依赖 cli；本模块依赖 F05 + F02 + 提供 stage_guard 给 F07/F08/F09 复用。
9. **TDD 刚性**：先 Red 后 Green 再 Refactor。
10. **第 XV 条对齐清单**：与宪法第 V 条（智能体目录契约）/ 第 VI 条（Agent Loop 与 State）/ 第 XIII 条逐项对齐。
